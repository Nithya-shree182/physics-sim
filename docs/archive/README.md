# Archive

Pages from when the project used a **Franka Panda**, and the working notes the two halves of the project passed each other in the first week. They are kept as a record of
how the numbers and decisions came about. **Nothing here describes the UR10e**, links between these pages are not maintained, and most of the open problems they list were
closed, overturned or made moot by the move to the UR10e (see [../TODO.md](../TODO.md) and [../../DECISIONS.md](../../DECISIONS.md)).

| page | what it was |
|---|---|
| `ARM_CONFIG.md`, `SOURCES.md` | where each Panda parameter came from |
| `HANDOFF.md`, `CONTEXT.md`, `ANALYSIS_CONTEXT.md`, `STATUS_2026-11-09_early.md` | state-of-the-project notes, each superseded by the one after it |
| `OPEN_PROBLEMS.md` | the Panda-era problem board and the findings behind it |
| `NOTES_FOR_DEV.md`, `NOTES_FOR_NITHYA.md`, `REPLY_TO_ANALYSIS.md`, `PINOCCHIO_HANDOFF.md`, `INTEGRATION.md`, `WORK_SPLIT.md` | the hand-offs between the simulator side and the analysis side |
| `PICK_AND_GRIPPER.md`, `MOTION_STACK.md` | the finger-gripper pick and the motion design written before it was built |
| `PREVIEW_DETECTION.md` | an early stand-in for the detector, superseded by the real one |
| `DASHBOARD_PLAN.md` | the first dashboard plan; what was built is in `dashboard/README.md` |
| `POSSIBLE_REFERENCES.md` | an assessment of candidate repositories and papers (a literature note, not project state) |
